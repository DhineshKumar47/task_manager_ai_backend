# AI Task Manager – Backend

Node.js backend for an AI-powered task manager with real-time chat and task synchronization using WebSockets and an AI agent.

---

## 🚀 Features

- 🤖 AI-powered chat agent
- 📝 Task creation & listing via natural language
- 🔄 Real-time sync using WebSockets
- 🧠 Agent memory & conversation handling
- ⚡ Fast Node.js server

---

## 🧱 Tech Stack

- **Node.js**
- **Express**
- **WebSocket (ws)**
- **LangChain**
- **Google Gemini API**
- **UUID**
